# Motion

Motion confirms state change; it does not decorate static UI. Standard transitions use 100ms or
180ms durations. Storybook disables animation by default for deterministic tests. Choose **Motion
enabled** in the toolbar only when reviewing production motion.

All motion must respect `prefers-reduced-motion`. Indeterminate progress may move; determinate
progress must communicate the same information without animation.
