# Typography

Heron uses three deliberate families, bundled through `unplugin-fonts` and Fontsource. Interface
copy uses Inter Variable, headings use Barlow Condensed, and aligned measurements use Cascadia
Mono Variable. Unhead keeps `html lang` aligned with the active locale and loads Noto Sans SC
Variable for Chinese UI so `:lang(zh*)` stacks pick the matching face. Font family, size, weight,
line height, and tracking must come from typography tokens rather than local numeric values.

## Dense application roles

The desktop DAW uses a compact scale because many labels and measurements coexist onscreen.
Micro and caption text are reserved for secondary metadata; anything needed to complete a task
uses control size or larger.

## General UI scale

Reusable controls and documentation use the rem-based `--ui-font-size-xs` through
`--ui-font-size-5xl` scale. Use `xs` for supporting copy, `sm` for standard controls and body
copy, `md` for comfortable body copy, and `lg` through `5xl` for progressively stronger
headings. Product DAW surfaces use the dense roles above instead of inventing pixel values.

## Weight, leading, and tracking

- Use regular for body and measurements, medium for active controls, semibold for headings, and
  bold only for compact uppercase labels.
- Use normal leading for interface copy, compact leading for dense descriptions, and tight leading
  for headings.
- Use normal tracking by default. Wide, wider, and widest tracking are reserved for uppercase
  utility labels. Tight tracking is reserved for large display text; tighter tracking is reserved
  for tabular timecode.

Text required to operate the product must remain legible at 200% zoom and may not be replaced by an
unlabeled icon.
