# Workspaces

Heron uses standard density for workflows and compact density only for persistent musical chrome.

```text
┌ application menu / project identity ─────────────────────────┐
├ global transport and monitoring commands ────────────────────┤
├ browser ┆ primary musical canvas ┆ contextual inspector ─────┤
├─────────┴ optional editor or mixer dock ┴─────────────────────┤
└ engine, device, position, and operation status ───────────────┘
```

## Compact editor chrome

- Toolbars have an accessible name and keep their close or escape action outside the scrolling
  command region.
- Exclusive tools use arrow-key roving focus.
- Open clips or peers use text plus the signal rail; color is supplemental.
- Inspector fields expose labels and bounded spinbutton values.
- Only the musical canvas scrolls in two dimensions. Chrome remains locally operable.

See **Components / Workspace / Command surfaces** for the executable reference.
