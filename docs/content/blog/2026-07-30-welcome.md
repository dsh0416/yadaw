# Welcome to the development log

This blog is for short, public notes about building YADAW: milestones, design
trade-offs, and the work that does not always show up in the user manual or a
GitHub release.

Expect posts about the native audio runtime, the project archive, the desktop
UI, and the rough edges we are still shaping. The [user manual](/manual/)
remains the place for how to use the app today; this log is about how the
product is evolving.

If you want to follow along in the repository, the source lives on
[GitHub](https://github.com/dsh0416/yadaw).
