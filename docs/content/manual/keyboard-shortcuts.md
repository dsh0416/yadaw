# Keyboard shortcuts

Use <kbd>Cmd</kbd> on macOS and <kbd>Ctrl</kbd> on Windows or Linux unless a
row says otherwise.

## Projects

| Action               | Shortcut                                              |
| -------------------- | ----------------------------------------------------- |
| New project          | <kbd>Cmd/Ctrl</kbd> + <kbd>N</kbd>                    |
| Open project         | <kbd>Cmd/Ctrl</kbd> + <kbd>O</kbd>                    |
| Save project         | <kbd>Cmd/Ctrl</kbd> + <kbd>S</kbd>                    |
| Close project        | <kbd>Cmd/Ctrl</kbd> + <kbd>W</kbd>                    |
| Project settings     | <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>,</kbd> |
| Application settings | <kbd>Cmd/Ctrl</kbd> + <kbd>,</kbd>                    |

## Editing

| Action     | Shortcut                                              |
| ---------- | ----------------------------------------------------- |
| Undo       | <kbd>Cmd/Ctrl</kbd> + <kbd>Z</kbd>                    |
| Redo       | <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> |
| Cut        | <kbd>Cmd/Ctrl</kbd> + <kbd>X</kbd>                    |
| Copy       | <kbd>Cmd/Ctrl</kbd> + <kbd>C</kbd>                    |
| Paste      | <kbd>Cmd/Ctrl</kbd> + <kbd>V</kbd>                    |
| Select all | <kbd>Cmd/Ctrl</kbd> + <kbd>A</kbd>                    |

Editing commands apply to the active workspace or editor. A command can be
unavailable when the current selection does not support it.

## Transport and arrangement

| Action                                          | Shortcut                                   |
| ----------------------------------------------- | ------------------------------------------ |
| Play or pause                                   | <kbd>Space</kbd>                           |
| Start or stop recording                         | <kbd>R</kbd>                               |
| Go to beginning                                 | <kbd>Home</kbd>                            |
| Create a MIDI clip on a focused instrument lane | <kbd>Enter</kbd>                           |
| Move a focused track up or down                 | <kbd>Alt</kbd> + <kbd>↑</kbd>/<kbd>↓</kbd> |

## View

| Action                                 | Shortcut                                        |
| -------------------------------------- | ----------------------------------------------- |
| Toggle full screen on macOS            | <kbd>Ctrl</kbd> + <kbd>Cmd</kbd> + <kbd>F</kbd> |
| Toggle full screen on Windows or Linux | <kbd>F11</kbd>                                  |

Shortcut labels on Windows and Linux currently use `Ctrl` in the application
menu. Context-specific piano-roll commands are shown in that editor.
