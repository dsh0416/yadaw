# 低延迟模式

低延迟模式用于减少演奏监听路径上的插件延迟与延迟补偿等待。它一次优化一个逻辑
Output，但不会静音、关闭或重新路由其他 Output。

这是会话辅助功能，不是工程编辑。启用状态与目标不会写入工程，不会让工程进入
未保存状态，并会在关闭或重新打开工程后重置。

## 选择监听 Output

打开工程时，Heron 会将排序最前的逻辑 Output 选为默认目标。它通常是
**Output 1–2**；如果工程采用其他排序，也可能是别的 Output。

如需使用其他监听目标：

1. 停止走带。
2. 打开混音台，找到所需的 Output 条带。
3. 选择**设为低延迟监听目标**。
4. 选择顶栏中的**低延迟模式**。

同一时间只能有一个目标 Output。所有 Output 都会继续输出正常信号；只有通向选定
Output 的实时监听主路由会被优化。

启用或关闭模式、更换目标以及修改插件预算都只能在走带停止时进行。启用后，该
模式会在播放和录音期间继续生效。

## 哪些路径会被优化

Heron 会根据轨道控件自动识别监听源，无需额外把某个通道标记为监听通道。

以下信号可以成为监听源：

- 已配置硬件输入且实际生效的音频输入监听；
- 通过乐器插件进行的实时 MIDI 监听。

仅仅打开录音启用不会创建监听路径。已启用录音但关闭监听的轨道仍会正常录制，
但不会进入低延迟规划。

Heron 会沿监听源的 dry 主路由，经过共享 Bus，直到目标 Output。Send 仍使用普通
延迟补偿，因此 wet 返回可能晚于 dry 监听信号。较晚的 Sidechain 信号也不会迫使
监听主输入等待。其他 Output 与无关的回放分支会保留普通插件延迟补偿。

## 插件延迟预算

在**设置 → 音频 → 录音**中调整**低延迟插件预算**。默认值为 5 ms，可按 1 ms
步进设置为 0–50 ms。Heron 会根据当前工程采样率将其换算成采样数。

预算统计每条有效主路径上的插件声明延迟。如果某条路径超过预算，Heron 会从延迟
贡献最大的可旁路效果器开始临时旁路，并在每次选择后重新计算所有监听路径。

Instrument 插件永远不会被旁路。它们的延迟会被报告为“不可避免延迟”；即使仅
Instrument 延迟就超过预算，模式仍然可以成功启用。轨道、共享 Bus 和目标 Output
上的效果器都可能成为临时旁路候选。

低延迟临时旁路与插件自身的旁路或启用状态相互独立。它不会修改工程，并会在关闭
低延迟模式后消失。与保留延迟的普通旁路不同，临时旁路使用零延迟直通。

## 查看当前状态

顶栏 tooltip 会显示目标 Output、预算和临时旁路的插件数量。如果模式已启用，但
当前没有有效监听源通向目标，会显示**当前无监听路径**。这是正常状态，不是错误。

Effect Chain Graph 会标记延迟敏感路径以及由低延迟模式临时旁路的效果器，并显示
不可避免的 Instrument 延迟。

## 模式不会降低哪些延迟

低延迟模式只改变音频图，不会改变：

- 音频设备缓冲区大小；
- ADC 或 DAC 转换时间；
- 输入环形缓冲；
- 采样率转换延迟；
- 工程或设备采样率。

要获得尽可能低的往返延迟，应将低延迟模式与稳定且足够小的设备缓冲区配合使用。
如果出现 XRUN 或掉音，即使会增加一些硬件延迟，也应适当增大缓冲区。

由于监听路径优先于回放对齐，监听轨道以及与其合流的共享 Bus 可能暂时无法与其余
编曲保持严格 PDC 对齐，这是预期行为。需要判断最终时序、效果和混音平衡时，请
关闭低延迟模式，以恢复完整补偿。

## 会话生命周期

- 隔离音频 helper 重启后会保留当前会话策略。
- 关闭、切换或重新打开工程会关闭该模式。
- 插件预算属于应用设置，会跨工程和应用重启保留。
- 如果目标 Output 被删除，模式会关闭，并将剩余 Output 中排序最前的一个选为新的
  默认目标。
