# 第一个工程

本教程将带你让声音通过 Heron，并保存一个小型会话。

## 1. 检查音频设备

打开**设置**，然后选择**音频 → 设备**。

1. 选择连接到扬声器或耳机的输出设备。
2. 如果打算录音，选择一个输入设备。
3. 选择缓冲区大小，可以从设备默认值或一个适中的值开始。
4. 选择**应用音频**。

状态栏会报告当前的采样率、缓冲区、往返延迟与 XRUN 计数。如果音频引擎没有
启动，请参阅[设置与音频设备](settings.md)。

## 2. 创建工程

在欢迎界面选择**创建工程**，并选择 `.heron` 归档的保存位置。

新工程的初始状态为：

- 48 kHz 会话采样率；
- 4/4 拍；
- 速度轨为 120 BPM。

之后可以在**文件 → 工程设置**中更改工程名称、采样率、拍号与波形显示。

## 3. 添加可播放的内容

从顶栏打开**混音台**。

- 选择**乐器**添加一条乐器轨，然后从输入槽或声音浏览器分配一个 VST® 3
  乐器。
- 选择**音频**添加一条音频轨，录音前先选择其硬件输入。

对于乐器轨，双击其时间线轨道上的空白处即可创建一个 MIDI 片段。选中该片段
并打开**钢琴卷帘**，即可绘制音符。

## 4. 使用走带

选择**播放**或按下 <kbd>Space</kbd>。播放头会在编排中移动，主输出电平表
会显示输出活动。按下 <kbd>Home</kbd> 回到开头。

双击音乐显示中的速度值，可以编辑当前位置的速度轨事件。

## 5. 保存

选择**文件 → 保存工程**，或按下 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> +
<kbd>S</kbd>。归档写入完成后，工程名称旁的未保存标记会消失。

::: info 工作副本与归档
工程打开期间，Heron 会维护一个活动的工作副本。保存会将该状态及其媒体
写入 `.heron` 归档。如果应用意外关闭，下次打开时 Heron 可以提议恢复较新
的工作副本。
:::
