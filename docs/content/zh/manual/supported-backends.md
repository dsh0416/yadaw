# 支持的后端与插件格式

在 Heron 中，**后端**是音频引擎与操作系统音频驱动之间的连接。VST 3、
Audio Unit 等插件格式则是另一层兼容机制，用于加载乐器与效果。

本页描述当前开发版本。即使 Heron 已包含某个后端，当对应驱动或设备无法
打开时，它仍可能显示为不可用。

## 音频后端

<AudioBackendSupportFigure />

**已支持**表示当前版本已经包含该后端；**已计划**表示它已进入未来计划，
但尚未包含在应用中，也不能选择。短横线表示该后端不面向相应操作系统。

| 后端       | Windows | macOS  | Linux  | 说明                                                       |
| ---------- | ------- | ------ | ------ | ---------------------------------------------------------- |
| WASAPI     | 已支持  | —      | —      | 使用 Windows 提供的音频设备。                              |
| ASIO®      | 已支持  | —      | —      | 需要 64 位 ASIO 驱动；输入与输出必须使用同一个 ASIO 驱动。 |
| CoreAudio  | —       | 已支持 | —      | 录音前需要授予 macOS 麦克风权限。                          |
| ALSA       | —       | —      | 已支持 | 设备访问与可用性取决于系统的 ALSA 配置。                   |
| JACK       | 已计划  | 已计划 | 已计划 | 三个平台均计划增加独立的 JACK 后端。                       |
| PipeWire   | —       | —      | 已计划 | 未来版本将增加原生 PipeWire 集成。                         |
| PulseAudio | —       | —      | 已计划 | 未来版本将增加独立的 PulseAudio 后端。                     |
| 模拟       | 已支持  | 已支持 | 已支持 | 无需音频硬件即可运行引擎；捕获为静音，播放会被丢弃。       |

在独立的 JACK、PipeWire 与 PulseAudio 后端完成之前，如果系统提供兼容桥接，
相应设备仍可能通过 ALSA 出现。

后端选择器只会显示当前构建已经包含的后端，并启用本机可用的项目；计划中的
后端目前不会出现。**模拟**后端始终可用，并列在最后作为回退。有关选择后端、
设备与缓冲区大小的操作，请参阅[设置与音频设备](settings.md)。

### 在 Windows 上选择后端

使用普通 Windows 音频设备时，可以先选择 WASAPI。使用专用音频接口时，
设备厂商提供的 ASIO 驱动通常能提供最直接的低延迟路径。请勿使用与设备
无关的驱动代替厂商驱动。

ASIO 会将一个驱动同时作为输入与输出设备，因此 Heron 无法组合两个不同
ASIO 驱动的输入与输出。WASAPI、CoreAudio 与 ALSA 可以独立选择输入和输出
设备；当两者时钟不同时，Heron 会使用自适应重采样与漂移校正。

## 插件与 Audio Unit 格式

| 格式              | 操作系统              | 状态   | 说明                                                                      |
| ----------------- | --------------------- | ------ | ------------------------------------------------------------------------- |
| VST® 3            | Windows、macOS、Linux | 已支持 | 支持乐器、效果、状态保存与编辑器窗口。                                    |
| 带 ARA 2 的 VST 3 | Windows、macOS、Linux | 已支持 | 当 VST 3 插件提供 ARA 2 扩展时可用；ARA 不会作为独立格式扫描。            |
| CLAP              | Windows、macOS、Linux | 已计划 | 当前版本不会扫描或加载。                                                  |
| Audio Unit（AU）  | macOS                 | 已计划 | 当前不会扫描或加载 `.component` 包；如产品提供 VST 3 版本，请改用该版本。 |
| VST 2 与 AAX      | —                     | 不支持 | 不会扫描或加载这些格式。                                                  |

当前插件目录只扫描 VST 3 位置。Heron 内置的 Gain、Sine 与 Metronome 处理器
也以 VST 3 插件形式提供。如果只安装了某个产品的 Audio Unit 版本，它不会
出现在 Heron 中。

::: tip Linux 编辑器窗口
在使用 Wayland 的 Linux 环境中，插件的原生 VST 3 编辑器可能不可用。
Heron 可以回退到通用参数编辑器；原生 Wayland 编辑器路径仍在计划中。
:::

有关扫描、插入与排查受支持插件的操作，请参阅
[VST 3 插件](plugins.md)。
