# MIDI 与钢琴卷帘

乐器轨承载 MIDI 片段，并将其中的音符发送给 VST3 乐器。

## 创建乐器轨

1. 打开**混音台**并选择**乐器**。
2. 选择空的乐器输入槽。
3. 搜索 VST3 乐器并选择一种受支持的音频模式。
4. 在编排中双击乐器轨，创建一个 MIDI 片段。

之后双击乐器槽即可打开插件编辑器。

## 导入 MIDI

使用 MIDI 导入命令并选择一个标准 MIDI 文件。导入对话框会列出其中的序列
与音符数量。

对于每个序列：

- 选择**新建乐器轨**，并可选地分配一个 VST3 乐器；或
- 选择**忽略**。

选择保留当前工程速度轨，还是导入文件的速度映射。保留工程速度会把 MIDI
放在播放头位置；导入速度则从 tick 0 开始，并替换现有的速度映射。

## 打开钢琴卷帘

选择一个 MIDI 片段，然后在顶栏选择**钢琴卷帘**。下方停靠区会显示可编辑的
片段、音符网格、检查器，以及可选的力度轨。

## 编辑工具

- **选择**：移动、缩放与编辑已有音符。
- **绘制**：添加音符。
- **擦除**：移除音符。
- **吸附**：将音符位置与长度约束到所选的音乐网格。
- **量化**：将所选音符的起始位置对齐到当前吸附网格。

检查器可以编辑当前选中音符的音高、起始 tick、时长、通道、力度与释音
力度。在力度轨中拖动条块，可以直观地塑造动态。

吸附选项包括从全音符到 64 分音符的均分与三连音数值。**关**则保持整数
tick 精度，不吸附到任何音符时值。

## 常用的音符编辑按键

标准编辑命令——剪切、复制、粘贴、全选、撤销与重做——作用于当前活动的
编辑器。钢琴卷帘还支持用键盘创建副本、八度移调与量化；编辑器中的命令
提示会反映当前的选区与工具。
