# 混音台与路由

从顶栏打开**混音台**，查看工程中的每一条音频、乐器、辅助轨道、输出与主输出
通道。

<RoutingPlayground />

## 看懂通道条

每条通道条自上而下跟随信号流向：

1. **输入**——硬件输入、总线输入或 VST® 3 乐器。
2. **音频效果**——有序的 VST 3 效果插入。
3. **发送**——路由到其他位置的信号副本。
4. **输出**——总线或硬件输出目标。
5. **声像**与**音量**——通道摆位与最终电平。

通道条还在适用时提供录音启用、输入监听、静音、独奏、电平表与通道菜单。

## 选择输入

音频通道可以接收：

- 单声道硬件输入；
- 相邻链接的立体声对；
- 总线。

乐器通道接收其分配的 VST 3 乐器的输出。辅助轨道通常通过总线或发送接收
音频。

## 路由到输出

使用**输出**部分选择下一级总线或硬件输出通道。硬件输出将其左右两侧映射
到当前输出设备提供的通道。

避免创建把信号送回自身的路由。Heron 会保持音频图合法，并拒绝无效的
拓扑。

## 添加发送

选择一个空的发送槽位，然后选择：

- 目标总线或输出；
- **前置**、**后置**或**声像后**的拾取位置；
- 发送电平；
- 启用或禁用状态。

需要独立的监听或效果电平时，使用推子前发送。需要发送量跟随通道音量时，
使用推子后发送。

## 总线与辅助轨道

辅助轨道用于处理共享的返回或子混音。将通道或发送路由到它的总线，在辅助
轨道上添加效果，然后把辅助轨道继续路由到主输出路径或硬件输出。

## 电平监测

让通道与主输出的峰值低于削波。随着余量耗尽，电平表会从绿色经黄色变为
红色。某一级削波时，降低信号源、插件输出或通道电平；只降低最终的主输出，
可能会让前面的一级继续过载。
