# 工作室界面

工作室将编排置于中心，并在其周围打开各类辅助工具。

## 顶栏

顶栏按功能分组：

- **资料库**：打开声音浏览器。
- **混音台**：打开或关闭下方的混音台停靠区。
- **钢琴卷帘**：为选中的 MIDI 片段打开。
- **走带**：回到开头、播放或暂停，以及录音。
- **音乐显示**：显示播放头位置、速度与拍号。
- **节拍器**：开关节拍器通道。
- **主输出**控件：快速查看主输出电平与电平表。

标注为“即将推出”的灰色控件暂不可用。

## 编排

编排将各轨道对齐到一条共享的音乐标尺上。速度、拍号与调号全局轨道位于通道
轨道上方。音频片段显示波形；MIDI 片段表示音符区域。

使用编排底部的控件可以调整：

- **时间**——以每四分音符像素数为单位的水平缩放；
- **轨道**——轨道高度；
- **增益**——波形显示比例，不改变音频电平。

双击缩放控件即可恢复默认值。

## 声音浏览器

选择**资料库**可以搜索：

- VST® 3 乐器；
- VST 3 音频效果；
- 已存入工程的音频；
- 已扫描的插件目录。

在 YADAW 打开期间安装了新插件后，请使用**重新扫描 VST3**。

## 下方停靠区

下方停靠区显示**混音台**或**钢琴卷帘**。拖动水平分隔条可以调整其高度。
打开其中一个会替换另一个；编排始终显示在其上方。

## 状态栏

状态栏汇总音频引擎的状态：

- 运行或停止状态；
- 采样率与位深；
- I/O 缓冲区大小；
- 当前与平均往返延迟；
- XRUN 计数。

当会话压力较大时，选择性能指示器可以检查 CPU、内存、时序与音频走带诊断。
