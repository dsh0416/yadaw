# VST3 插件

YADAW 会从标准的系统与用户位置发现 VST3 乐器与效果。插件运行在隔离的
音频宿主进程中，因此失败的模块可以被报告并隔离，而无需将原生代码直接
加载到界面中。

## 扫描目录

YADAW 会在启动时扫描。安装新插件后要重新查找：

1. 打开**资料库**；
2. 选择插件目录；
3. 选择**重新扫描 VST3**。

启动与扫描视图会报告发现的插件包、可用的插件，以及无法加载的模块。

## 添加乐器

添加一个乐器通道，然后选择其**乐器**输入槽。按名称或厂商搜索并选择插件。

如果乐器支持多种布局，请在加载前选择其音频模式。乐器模式包括单声道与
立体声输出。

## 添加效果

在任何兼容的混音台通道上：

1. 选择**音频效果**下的空槽位；
2. 搜索 VST3 效果目录；
3. 选择一种受支持的模式；
4. 选择已加载的插入以打开其编辑器。

效果可能支持单声道、立体声、单声道转立体声或双单声道布局。不受支持的
模式在选择器中不可用。

## 管理插入

插入可以：

- 在其原生编辑器中打开；
- 旁路后再次启用；
- 移动到其他槽位；
- 移除；
- 切换到其他受支持的音频模式。

在支持撤销的操作中，更改或移除插件会记入工程历史。

## 缺失或失败的插件

当存储的插件缺失、被隔离或无法启动时，工程会保持合法的信号路径。检查
槽位状态与目录状态，然后：

1. 确认安装了正确的插件与架构；
2. 重新扫描目录；
3. 如果插件是在宿主运行期间安装的，请重启 YADAW；
4. 旁路或移除反复失败的插件。

永远不要假设名称或厂商相似的两个插件可以互换；它们的标识符与已保存
状态可能不同。
