# 录制音频与 MIDI

录音需要活动的音频引擎。开始录音前，请至少启用一条音频轨、乐器轨，或两者。

## 准备系统

1. 打开**设置 → 音频 → 设备**。
2. 选择输入与输出设备。
3. 应用配置，并确认状态栏显示**音频运行中**。
4. 在**音频 → 录音**中选择录音格式与交换位置。
5. 若使用 MIDI 硬件，打开**设置 → MIDI 输入与同步**，确认预期端口可用。

缓冲区要小到可以舒适监听，又要大到足以避免 XRUN。可以先用较大的值，待
信号稳定后再逐步减小。

## 准备音频轨

1. 打开**混音器**并添加一条**音频**轨。
2. 在通道的**输入**区域选择单声道硬件输入，或将相邻通道配对为立体声。
3. 打开该轨的**录音启用**。
4. 若要通过 YADAW 监听输入，打开**输入监听**。

软件监听必须在录音设置中启用，且该轨必须有硬件输入，输入监听才可用。

::: warning 反馈
不要通过附近的扬声器监听开放麦克风。请使用耳机，或关闭监听以防反馈。
:::

## 准备乐器轨

1. 打开**混音器**并添加一条**乐器**轨。
2. 在轨道的 MIDI 输入控件中选择端口与通道，或保留默认的全部输入 / Omni。
3. 打开该轨的**录音启用**。
4. 若希望演奏时实时送到乐器，打开**输入监听**。

录音不依赖监听。即使关闭监听，已启用录音的乐器轨仍会写入 MIDI 日志。

## 捕获

将播放头移到起始位置，然后选择**录音**或按 <kbd>R</kbd>。已启用录音的音频轨
会捕获所选输入；已启用录音的乐器轨会把匹配的 MIDI 写入持久日志，并在停止时
提交为 MIDI 片段。

再次选择**录音**即可停止。YADAW 会关闭录音、必要时修复音频头、将音频处理为
工程资源、把 MIDI 日志转换为片段，并更新编曲。最终化对话框显示时请保持应用
程序打开。

## 恢复

捕获过程中，音频与 MIDI 日志会写入配置的交换目录。因此即使录音或应用程序在
保存工程归档前停止，YADAW 也能恢复该次录音。恢复 MIDI 录音时，会关闭捕获结束
时仍按住的音符。

成功捕获后：

1. 播放新片段并检查；
2. 保存工程归档；
3. 为重要工作保留外部备份。

## 如果录音丢帧

XRUN 或丢帧警告表示音频回调未能按时接收或送达数据。请停止录音、增大缓冲区、
关闭占用 CPU 的应用或插件，然后重试。YADAW 会在最终化时报告丢弃的输入或已捕获
帧数，而不是隐藏问题。
