# 录制音频

录音需要一个活动的输入设备、一条音频轨，以及一个选定的硬件输入。

## 准备系统

1. 打开**设置 → 音频 → 设备**。
2. 选择输入与输出设备。
3. 应用配置，并确认状态栏显示**音频运行中**。
4. 在**音频 → 录音**中选择录音格式与交换位置。

缓冲区要小到可以舒适监听，又要大到足以避免 XRUN。可以先用较大的值，待
信号稳定后再逐步减小。

## 准备轨道

1. 打开**混音台**，添加一条**音频**轨。
2. 在通道的**输入**部分，选择一个单声道硬件输入，或将相邻的一对链接为
   立体声。
3. 打开轨道的**录音启用**。
4. 如果需要经由 YADAW 听到输入，打开**输入监听**。

必须先在录音设置中启用软件监听，并为轨道选择硬件输入，输入监听才可用。

::: warning 回授
不要通过附近的扬声器监听打开的麦克风。请使用耳机或关闭监听，以防产生
回授。
:::

## 捕获

将播放头移动到起始位置，然后选择**录音**或按下 <kbd>R</kbd>。启用录音的
音频轨会捕获其选定的输入。

再次选择**录音**即可停止。YADAW 会关闭录音、修复其音频头、将其处理为
工程资源，并创建一个编排片段。在完成对话框处于活动状态时，请勿关闭应用。

## 恢复

捕获期间，音频会写入配置的交换目录。这样，即使录音或应用在工程归档保存
前停止，YADAW 也能恢复这条录音。

捕获成功后：

1. 播放新片段并检查；
2. 保存工程归档；
3. 为重要的工作保留一份外部备份。

## 如果录音丢帧

XRUN 或丢失警告意味着音频回调没有按时接收或交付数据。请停止录音，增大
缓冲区，关闭占用 CPU 较高的应用或插件，然后重试。在完成阶段，YADAW 会
如实报告被丢弃的输入帧或已捕获帧，而不是掩盖问题。
