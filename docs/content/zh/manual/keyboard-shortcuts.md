# 键盘快捷键

除非某一行另有说明，macOS 上使用 <kbd>Cmd</kbd>，Windows 或 Linux 上使用
<kbd>Ctrl</kbd>。

打开**系统设置 → 键盘 → 快捷键**可以更改键盘绑定，或分配 MIDI 音符或
控制变更消息。选择一个键盘绑定，然后按下新的组合键。对于 MIDI，选择
**MIDI 学习**，然后按下打击垫、琴键或控制器按钮。MIDI 控制变更绑定在值
越过 64 时触发，并在低于 64 时重置。

**全部重置**会恢复下方列出的默认值。快捷键也可以保持未分配状态。

## 工程

| 操作         | 快捷键                                                |
| ------------ | ----------------------------------------------------- |
| 新建工程     | <kbd>Cmd/Ctrl</kbd> + <kbd>N</kbd>                    |
| 打开工程     | <kbd>Cmd/Ctrl</kbd> + <kbd>O</kbd>                    |
| 保存工程     | <kbd>Cmd/Ctrl</kbd> + <kbd>S</kbd>                    |
| 关闭工程     | <kbd>Cmd/Ctrl</kbd> + <kbd>W</kbd>                    |
| 工程设置     | <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>,</kbd> |
| 应用程序设置 | <kbd>Cmd/Ctrl</kbd> + <kbd>,</kbd>                    |

## 编辑

| 操作 | 快捷键                                                |
| ---- | ----------------------------------------------------- |
| 撤销 | <kbd>Cmd/Ctrl</kbd> + <kbd>Z</kbd>                    |
| 重做 | <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> |
| 剪切 | <kbd>Cmd/Ctrl</kbd> + <kbd>X</kbd>                    |
| 复制 | <kbd>Cmd/Ctrl</kbd> + <kbd>C</kbd>                    |
| 粘贴 | <kbd>Cmd/Ctrl</kbd> + <kbd>V</kbd>                    |
| 全选 | <kbd>Cmd/Ctrl</kbd> + <kbd>A</kbd>                    |

编辑命令作用于当前活动的工作区或编辑器。当当前选区不支持某条命令时，该
命令可能不可用。

## 走带与编排

| 操作                           | 快捷键                                     |
| ------------------------------ | ------------------------------------------ |
| 播放 / 暂停                    | <kbd>Space</kbd>                           |
| 开始 / 停止录音                | <kbd>R</kbd>                               |
| 返回开头                       | <kbd>Home</kbd>                            |
| 切换混音台                     | <kbd>M</kbd>                               |
| 在聚焦的乐器轨上创建 MIDI 片段 | <kbd>Enter</kbd>                           |
| 上下移动聚焦的轨道             | <kbd>Alt</kbd> + <kbd>↑</kbd>/<kbd>↓</kbd> |

## 视图

| 操作                           | 快捷键                                          |
| ------------------------------ | ----------------------------------------------- |
| 在 macOS 上切换全屏            | <kbd>Ctrl</kbd> + <kbd>Cmd</kbd> + <kbd>F</kbd> |
| 在 Windows 或 Linux 上切换全屏 | <kbd>F11</kbd>                                  |

在 Windows 与 Linux 上，应用菜单中的快捷键标签目前使用 `Ctrl`。特定于
钢琴卷帘的命令显示在该编辑器中。
